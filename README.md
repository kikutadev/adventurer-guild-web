# Adventurer Guild web build

Public compiled GitHub Pages artifact for the Adventurer Guild reference product from the private `idle-game-kit` source repository.

- Reference release: `adventurer-guild-v0.11.1`
- This repository contains the playable compiled web build, not the reusable kit source.
- v0.11.0 replaced Party slots with direct per-Area adventurer allocation and visible strengthening impact.
- v0.11.1 adds before/after Gold and exploration previews for bulk Area staffing while keeping the v0.11.0 save-definition contract.
- Third-party game assets remain subject to their original terms; see `THIRD_PARTY_NOTICES.md`.
